Point it at a TSV.
Get English in Solr.

Hosted translation APIs do not finish a million rows. BigTranslate splits the file, runs Pantogloss locally — glossary, then cache, then the model — and posts the English into Solr while you watch. 

$ bin/bigtranslate translate ~/untranslated

The strings that matter

The model is for the sentence. The glossary is for the formula.

Pantogloss will render a job title. It will also turn Medio Tiempo into “Half Time” and Correo Electrónico into “default mail” unless you stamp those first. The 69 overrides are not the story of the model. They are why re-runs stay consistent.

One command

translate hides the MapReduce.

  1. split~1000-line chunks
  2. tsvtojsonETLLib, one file
  3. repackageOne JSON per job
  4. pantoglossColumns in translate.cols
  5. posterSolr bigtranslate

The corpus

A directory of TSV. One record per line.

Country-day files. The crawler picks them up from staging. Exclude .git if you pointed it at a checkout.

Offline

No hosted API. A local many-to-English model.

Pantogloss is TensorFlow/Keras on the box. Tested on up to 190 million rows on 16-core nodes.

Watch it

OPSUI for the workflow. Gloss for Translate / Reset, the map, the table, and facets. Solr core bigtranslate.

Reset and go again

bigtranslate reset --yes wants the services down. Gloss Reset is a live wipe and keeps the translation cache.

Setup once

PANTOGLOSS_SOURCE=~/git/pantogloss bin/bigtranslate-setup then oodt restart. The PGEs inherit the workflow manager’s PATH.

Gloss

The console is a path and a button.

Gloss is the Vue 3 UI at /gloss/. You paste a directory of TSV files, press Translate, and the map fills as Solr receives postings. Reset is the other button. The phases stay in bin/bigtranslate.

bin/bigtranslate

The operator path.

$ PANTOGLOSS_SOURCE=~/git/pantogloss bin/bigtranslate-setup
$ bin/oodt start
$ bin/bigtranslate translate --exclude .git ~/untranslated
$ bin/oodt stop
$ bin/bigtranslate reset --yes

One verb for the whole corpus, reset before the next tree. oodt start is the Mnemosyne launcher — the name is unchanged on purpose.
